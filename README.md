# Absensi Santri - Ponpes Maslakunnidzom

Aplikasi absensi santri berbasis web untuk administrasi harian di Ponpes Maslakunnidzom. Project ini dibuat sebagai single-page app menggunakan HTML, CSS, dan JavaScript, tanpa framework backend.

## Fitur utama
- Input dan monitoring kehadiran santri per hari
- Status kehadiran: Hadir, Sakit, Izin, Alpha, Terlambat
- Kalender harian untuk navigasi tanggal
- Daftar santri dengan ringkasan kehadiran
- Import/unggah data santri dari file Excel
- Export data rekap ke format Excel
- Tampilan dashboard yang sederhana dan siap digunakan untuk operasional pondok

## Stack
- HTML
- CSS
- JavaScript
- Tailwind CSS CDN
- SheetJS (xlsx) untuk Excel

## Struktur proyek
- `index.html` — seluruh aplikasi utama (UI, logic, dan styling dalam satu file)

## Cara pakai
1. Buka file `index.html` di browser
2. Upload data santri atau masukkan data sesuai kebutuhan aplikasi
3. Pilih tanggal absensi
4. Tandai status setiap santri
5. Simpan atau ekspor hasil absensi ke Excel bila diperlukan

## Catatan
Project ini bersifat frontend-only dan cocok untuk kebutuhan absensi manual sederhana di lingkungan pesantren atau lembaga pendidikan.

## Lisensi
Project ini belum mencantumkan lisensi resmi.
